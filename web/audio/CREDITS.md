# Audio credits

The play buttons on individual readings use these recordings, bundled with the app.

## cmn/ — Mandarin syllables

- Source: [hugolpz/audio-cmn](https://github.com/hugolpz/audio-cmn), "syllabs v.2" set
  (`24k-abr/syllabs`), commit `f759a0f18f27690742957619e1248ed91e9b3f2c`.
- Speaker: Chen Wang.
- Licence: CC BY-SA, as stated in the repository README (which gives no version).
  The files are copied unchanged.
- Files are named `cmn-{pinyin}{tone}.mp3` (ü written as v). The neutral tone has no recordings.

## vie/ — Vietnamese syllables

- Source: [Wikimedia Commons](https://commons.wikimedia.org/) / [Lingua Libre](https://lingualibre.org/),
  speaker "Penn Zero MSSJ" (listed as Hanoi on Wiktionary), files
  `LL-Q9199 (vie)-Penn Zero MSSJ-{word}.wav`. Licence: [CC0](https://creativecommons.org/publicdomain/zero/1.0/).
- Changes: converted to mono 48 kbps mp3, with the peak level normalised. Each file is named after
  the syllable it says.
- Southern-speaker recordings were left out, because the app's Vietnamese readings are Northern
  (standard). Syllables without a Hanoi recording use the device's Vietnamese voice instead.
