# 📘 **Reading Baxter–Sagart Old Chinese (OC) & Middle Chinese (MC)**

*A Practical Guide for Linguistic Research*

---

## 🀄 1. Old Chinese (OC) – Baxter–Sagart (2014)

Baxter–Sagart OC reconstruction is **not IPA**.
It is a **structural notation** that encodes historical features of Old Chinese.

Examples:

```
*kʰˤaʔ
*N-qˤro[t]-s
*m̥ˤrəp
*Cə.kˤan-s
```

---

### 1.1 Structure of an OC Syllable

Every OC syllable follows this pattern:

```
(PREFIX) – INITIAL (ˤ?) – MEDIAL – VOWEL – CODA – (SUFFIX)
```

Example:

```
*N-qˤro[t]-s
```

Breakdown:

* **N-** → nasal prefix
* **qˤ-** → pharyngealized uvular initial
* **ro** → root syllable
* **[t]** → *allophonic “ghost coda”* (not pronounced)
* **-s** → departing-tone suffix

---

### 1.2 Initial Consonants

Common OC initials:

| Symbol     | Meaning             |
| ---------- | ------------------- |
| p, t, k    | voiceless stops     |
| b, d, g    | voiced stops (rare) |
| q          | uvular stop         |
| ts, s, z   | sibilants           |
| m, n, ŋ    | nasals              |
| r          | rhotic              |
| l          | lateral             |
| ʔ          | glottal onset       |
| pʰ, tʰ, kʰ | aspirated stops     |
| m̥, n̥, ŋ̊ | voiceless nasals    |

---

### 1.3 Pharyngealization: ˤ

The superscript **ˤ** means **pharyngealization** (a “dark” or “backed” consonant).

Examples:

* `kˤa` → backed “ka”
* `qˤro` → backed uvular “kro”

You do **not** pronounce “ˤ” separately.
It simply modifies the quality of the vowel.

---

### 1.4 OC Prefixes and Derivational Morphology

These are hypothesized **morphological elements** that occurred before the root syllable. They often left phonological traces in Middle Chinese (MC) tone or initial class, even if they’re not pronounced anymore.

| Prefix | Function / Meaning                       | Phonetic Effect                                               |
| ------ | ---------------------------------------- | ------------------------------------------------------------- |
| `s-`   | Derivational or causative prefix         | Triggers departing tone (去聲, qu) in MC; may affect aspiration |
| `N-`   | Nasal prefix (unspecified nasal)         | May cause voicing in initials; contributes to tone shifts     |
| `C-`   | Consonantal prefix (generic placeholder) | Stands for a possible unclassified consonant                  |
| `r-`   | Rhotic prefix                            | May color vowels; sometimes causes pharyngealization          |
| `ng-`  | Velar nasal prefix                       | May lead to voiced or breathy initials in MC                  |

> These prefixes are not read aloud — they represent historical derivation.

---

### 1.5 Roots / Rimes

These are the **core parts** of the syllable — the rhyme (vowel + coda), typically corresponding to the MC rime.

| Rime Example     | Description                                                           |
| ---------------- | --------------------------------------------------------------------- |
| `-an`            | Nasal rime ending in /n/                                              |
| `-aj`            | Diphthong /aj/, common in MC rising tones                             |
| `-əp`, `-at`     | Stop-final rimes from MC checked tone (入聲)                            |
| `-a[t]`, `-a[n]` | Bracketed codas: reconstructed from MC tone/cognates — not pronounced |

---

### 1.6 Tonal Suffixes

These are historical **suffixes in Old Chinese** that led to the emergence of tones in Middle Chinese. They are part of the tonogenesis process.

| Suffix           | OC Role                               | Leads to MC Tone    |
| ---------------- | ------------------------------------- | ------------------- |
| `-s`             | Derivational suffix                   | Departing tone (去聲) |
| `-ʔ`             | Glottal suffix (exclamative/emphatic) | Rising tone (上聲)    |
| *(none)*         | Absence of suffix                     | Level tone (平聲)     |
| `-p`, `-t`, `-k` | Real stop codas                       | Checked tone (入聲)   |

---

### 1.7 Tone Categories (A, B, C, D)

These tone labels map OC suffixes to **Middle Chinese tonal categories**.

| Tone       | Label | OC Trigger                  | Description    |
| ---------- | ----- | --------------------------- | -------------- |
| 平聲 (píng)  | A     | No suffix                   | Level tone     |
| 上聲 (shǎng) | B     | Glottal stop `-ʔ`           | Rising tone    |
| 去聲 (qù)    | C     | `-s` suffix                 | Departing tone |
| 入聲 (rù)    | D     | Final stop `-p`, `-t`, `-k` | Checked tone   |

---

### 1.8 Derivation Examples (OC → MC Structure)

| Derivation Pattern (Column D) | Reconstructed OC (Column E) | Explanation                                                            |
| ----------------------------- | --------------------------- | ---------------------------------------------------------------------- |
| `(- + -aj C)`                 | `*qʰa[t]-s`                 | No prefix; root `-aj`; tone C → [t] ghost coda + `-s` departing suffix |
| `(ng- + -aj C)`               | `*C.ŋˤa[t]-s`               | Velar nasal prefix; root `-aj`; departing tone                         |
| `(- + -an A)`                 | `*[ʔ]a[n]`                  | No prefix; nasal rime; level tone → glottal onset, nasal coda          |

---

### 1.9 Medials

Medials appear between initial and vowel:

| Symbol | Meaning         |
| ------ | --------------- |
| -r-    | rhotic coloring |
| -j-    | palatal medial  |
| -w-    | labial medial   |

Example: `kʷˤar` → roughly “kwar”

---

### 1.10 Vowels

| Vowel | Value (approx.) |
| ----- | --------------- |
| a     | “ah”            |
| e     | “eh”            |
| o     | “aw/o”          |
| ə     | “uh”            |
| i     | “ee”            |
| u     | “oo”            |
| r̩    | syllabic “r”    |

---

### 1.11 Codas (Final Consonants)

OC codas include **phonemic codas** and **bracketed allophones**.

**Real codas:**

```
-p, -t, -k, -m, -n, -ŋ, -r, -ʔ
```

**Bracketed codas (not pronounced):**

```
[t], [p], [k]
```

These are **morphophonological placeholders**, not phonetic.

---

### 1.12 The -s Suffix

`-s` is extremely common. It:

* Marks departing-tone (去聲) developments
* Was likely a weak /s/ suffix in speech

Example:

```
*kˤat-s  → MC 去聲  → Mandarin 4th tone
```

---

### 1.13 General Rule for Pronunciation of OC

* **Ignore bracketed codas**: `[t]`, `[p]`, `[k]`
* **Ignore prefixes when reading aloud** (`N-`, `C-`, `s-`, etc.)
* **Pronounce only the main root syllable**
* **ˤ modifies the vowel quality**

OC is **not meant to be spoken**, only structurally interpreted.

## 🎐 2. Middle Chinese (MC)

Middle Chinese reconstructions **are phonemic** and **pronounceable**.

Example MC forms (as written in the **Middle Chinese** column of this app):

```
liX      (rising)
tsyhaeH  (departing)
kaep     (entering — note the final -p, no tone letter)
nyen     (level — no tone letter)
```

---

### 2.1 MC Syllable Structure

```
INITIAL – MEDIAL – VOWEL – CODA – TONE
```

MC does **not** use OC-style prefixes or bracketed codas.

---

### 2.2 MC Tone Markers (Baxter notation)

In Baxter's transcription only **two** tones get a letter; the other two are
unmarked (you tell them apart from the coda):

| Marker | Tone | Traditional Name | How it's written | Example (in this dataset) |
| --- | --- | --- | --- | --- |
| *(none)* | Level | 平聲 | no letter | `then` (天), `sej` (西) |
| **X** | Rising | 上聲 | trailing `X` | `maeX` (馬) |
| **H** | Departing | 去聲 | trailing `H` | `kaH` |
| *(none)* | Checked / entering | 入聲 | no letter — the **-p/-t/-k** coda *is* the marker | `lik` (力), `dzyip` (十), `pjot` (發) |

> ⚠️ There is **no** "A" or "P" letter in Baxter notation — level and entering
> tones carry no tone letter at all. (Some scholars label the four categories A/B/
> C/D abstractly, as in §1.7, but those letters are **not written in the
> transcription**.)

### Quick mental equivalents:

* level (unmarked) → Cantonese tone 1 or 4 / Mandarin 1 or 2
* **X** → Cantonese tone 2 or 5 / Mandarin 3
* **H** → Cantonese tone 3 or 6 / Mandarin 4
* checked (ends -p/-t/-k) → Cantonese tones 7, 8, 9 (lost in Mandarin)

---

### 2.3 MC Codas

MC codas are real and should be pronounced.

### Nasals:

```
-m, -n, -ŋ
```

### Stop codas (checked tone):

```
-p, -t, -k  → always tone P
```

### Open syllables:

```
-a, -e, -o, -i, -u
```

Unlike OC, **nothing is in brackets**.

---

### 2.4 Pronouncing MC Examples

* **liX** → /li˧˦/ (rising “li”)
* **tsyhaeH** → departing-tone “tshae”
* **kaep** → /kæp̚/ (entering tone — final -p, no tone letter)
* **nyen** → /ɲen/ (level tone — no tone letter)

> In this app, the **Middle Chinese** row shows exactly this Baxter
> *transcription*; the **Middle Chinese (Baxter)** row shows the same syllable as
> reconstructed **IPA**, with the tone as a superscript digit (¹ level · ² rising
> · ³ departing · ⁴ entering), e.g. 力 → `lik` ↔ `lik⁴`.

---

## 🎯 3. OC → MC → Modern Reflexes (Quick Guide)

* **OC -s** → MC 去聲 (H) → Mandarin 4th tone
* **OC -ʔ** → MC 上聲 (X) or 入聲 (P) depending on dialect
* **OC pharyngealization ˤ** often → back vowels in MC
* **OC prefixes** explain voicing alternations across MC initials

MC then feeds:

* Mandarin tones
* Cantonese tones
* Hokkien entering tones
* Korean/ Japanese Sino-Xenic reflexes

---

## 🧭 4. What to Ignore vs. What to Read

### Old Chinese (OC)

| Symbol Type                | Read Aloud?               | Meaning            |
| -------------------------- | ------------------------- | ------------------ |
| Prefixes (N-, s-, C-, ʔ-)  | ❌ ignore                  | morphological only |
| Bracketed codas ([t], [k]) | ❌ ignore                  | allophonic         |
| ˤ                          | ✔ modify vowel            | pharyngealization  |
| -s                         | ✔ weak /s/ or tone marker | departing suffix   |

### Middle Chinese (MC)

| Symbol Type          | Read Aloud? | Meaning         |
| -------------------- | ----------- | --------------- |
| Tone markers A/X/H/P | ✔ yes       | phonemic tones  |
| Codas (p/t/k/m/n/ŋ)  | ✔ yes       | real finals     |
| Vowels               | ✔           | real vowels     |
| Initials             | ✔           | real consonants |

---

## ✔ Summary

* **OC = structural, historical, partly unpronounceable**
* **MC = phonemic, pronounceable**
* Ignore OC bracketed codas but keep MC finals.
* `ˤ` = pharyngealization.
* `-s` = OC → MC
